# Stick Online–inspired PWA

A browser PWA game inspired by **Stick Online** — original name, original art, no copied assets.
Inspired-by, not a clone.

## Status
- Phase 1 (research): in progress — gameplay deep-dive (combat, progression, classes/skills, items/economy, multiplayer, world structure, quests).
- Phase 2 (design proposal): pending research.
- Phase 3 (build): only after design approval.

Target stack: plain HTML/CSS/JS + service worker PWA, deployed on GitHub Pages — same pattern as Void Wars.
